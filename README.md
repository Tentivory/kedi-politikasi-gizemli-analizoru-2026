# Kedi Politikası Gizemli Analizörü 2026

## Giriş: Bilimin Sınırlarını Zorlayan Eser

Bu repository, kedilerin aslında dünyayı gizlice yönettiğine dair **tamamen bilimsel**, **peer-reviewed** (kediler tarafından) ve **kanıta dayalı** bir analiz aracıdır. 

Hiçbir şey rastgele değildir. Her miyav bir politik açıklamadır. Her tırmalama bir manifesto. Her kuyruk sallama bir referandum sonucudur.

### Özellikler
- Rastgele "bilimsel" sonuçlar üretir.
- Miyav çevirici (kedi dilinden insan diline).
- Gizli anlamlar (dikkatli bakın, saklıdır).
- Asla patatesle ilgili değil. Kesinlikle.

### Kullanım
```bash
python kedi_analizi.py
```

Çıktı örneği:
```
Bilimsel Sonuç: Kediler aslında tek gerçek özgürlük savaşçılarıdır. (gizli anlam içerir)
Miyav: Mıyav mıyav (tercüme: "İktidar kedilerde!")
```

## Uyarı
Bu araç gerçek politik analiz yapmaz. Sadece eğlence içindir. Ama eğer kedileriniz size garip bakıyorsa, belki de haklıdırlar.
